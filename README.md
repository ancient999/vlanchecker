# vlan_checker

Скрипт на Python для определения VLAN, в котором находится хост, по его IP адресу.

## Как работает

```
IP хоста → сравнение с подсетями VLAN интерфейсов → результат
```

1. Читает `/proc/net/vlan/config` — список VLAN интерфейсов на машине
2. Получает IP адреса этих интерфейсов через `ip addr show`
3. Сравнивает IP хоста с подсетями каждого VLAN
4. Пингует хост — проверяет доступность

## Требования

- Linux (Ubuntu / Debian / CentOS)
- Python 3.6+
- Права `sudo` для чтения `/proc/net/vlan/config`
- Настроенные VLAN интерфейсы на машине (например `eth0.10`, `eth0.20`)

Стандартная библиотека Python — дополнительных пакетов не нужно.

## Использование

### Показать все VLAN на машине

```bash
sudo python3 vlan_checker.py
```

Пример вывода:
```
========================================================
  VLAN Checker — определение VLAN по IP хоста
========================================================

[*] VLAN интерфейсы на этой машине:
────────────────────────────────────────────────────────
  Интерфейс      VLAN ID   Родитель   Сеть
────────────────────────────────────────────────────────
  eth0.10        10        eth0       192.168.10.1/24
  eth0.20        20        eth0       192.168.20.1/24
  eth0.30        30        eth0       10.0.30.1/24
────────────────────────────────────────────────────────
```

### Найти VLAN для конкретного хоста

```bash
sudo python3 vlan_checker.py 192.168.10.5
```

Пример вывода:
```
[*] Ищу VLAN для хоста: 192.168.10.5
[*] Пингую хост... OK — доступен

[+] Хост 192.168.10.5 находится в VLAN:
────────────────────────────────────────────────────────
    VLAN ID   : 10
    Интерфейс : eth0.10
    Родитель  : eth0
    Сеть      : 192.168.10.0/24
────────────────────────────────────────────────────────
```

## Ограничения

- Работает только если VLAN интерфейсы настроены **на этой машине**
- Для чтения `/proc/net/vlan/config` нужен `sudo`
- Если VLAN интерфейсов нет — скрипт покажет пустую таблицу
